# End-to-End E-Commerce Dynamic Pricing Engine

An automated, closed-loop pricing optimization system built to bridge data engineering pipelines, machine learning forecasting, and an interactive operational dashboard.

---

## Project Overview
Manual pricing strategies fail to keep pace with fast-moving competitor markets and complex consumer demand shifts. This project solves that problem by building a complete end-to-end system that:
1. **Ingests & Cleans** raw market logs into a structured relational database (Data Engineering).
2. **Trains** a non-linear machine learning model to predict consumer price elasticity and revenue outcomes (Data Science).
3. **Serves** insights via an interactive web application with closed-loop write-back capabilities to instantly update store prices (MLOps / UI).
